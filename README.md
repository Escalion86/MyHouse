# Мой дом — 3D

Первая интерактивная версия по планам и фотографиям владельца. Два этажа, крыша, открытая мансарда, лестница, кабинет с убранным интерьером, наружные объёмы гаража и примыкающей бани. Расстояние до построек — 4,55 м. Исходные размеры: `HOUSE.md`, `house-data.json`. Допущения доступны кнопкой «Черновая геометрия».

## Запуск

Требуется Node.js 22.12+ (проверено на 24.11). В папке проекта:

```powershell
npm install
npm run dev -- --port 5173
```

Открыть http://localhost:5173. На телефоне в той же сети — http://IP-КОМПЬЮТЕРА:5173; при необходимости разрешить этому серверу доступ в частной сети в брандмауэре Windows. Скрипт `Start-Home.ps1` выполняет запуск. `npm run build` создаёт переносимую сборку в `dist`, `npm run preview -- --port 5173` показывает её. Никаких внешних шрифтов/CDN; после установки зависимостей сцена работает локально.

## Публикация на GitHub

Репозиторий: https://github.com/Escalion86/MyHouse. При отправке изменений в `main` GitHub Actions выполняет тесты и сборку. Готовая сборка доступна в артефакте `website-dist` соответствующего запуска.

Для публикации через GitHub Pages необходим поддерживающий закрытые репозитории тариф либо публичный репозиторий. В Settings → Pages выберите GitHub Actions, затем в Settings → Secrets and variables → Actions → Variables задайте `PAGES_ENABLED=true` и повторно запустите workflow `Build and deploy`. Адрес после успешной публикации: https://escalion86.github.io/MyHouse/.

Сайт GitHub Pages доступен через HTTPS. Для управления Home Assistant с него нужен доступный браузеру защищённый адрес HA (`https://` / `wss://`); локальный HTTP-адрес подходит для локального запуска проекта. Токен Home Assistant не включается в сборку и вводится пользователем.

## Управление

- Обзор: перетаскивание мышью, колесо, масштаб и сброс справа снизу.
- Прогулка: WASD или стрелки, перетаскивание мышью для поворота. На телефоне — экранные стрелки и перетаскивание сцены.
- Комната в списке переносит туда в режиме прогулки. По лестнице можно подниматься и спускаться обычными стрелками: камера плавно меняет высоту, этаж переключается автоматически.
- В коридоре кнопки «Подняться на 2 этаж» / «Спуститься на 1 этаж» ведут по ступеням с поворотом. «Остановиться», Escape, клавиши движения или перетаскивание сцены прерывают проход; затем можно продолжить вручную или кнопкой. Препятствия и пустая часть лестничного проёма блокируют движение.
- Устройства доступны в списке и по нажатию на 3D-объект.
- «Экспорт модели GLB» готовит все этажи, крышу и постройки, независимо от текущего вида. Затем нажать «Сохранить GLB». Готовый файл также находится в `exports/my-home-draft.glb`.

## Home Assistant

Адрес владельца: `http://192.168.1.232:8123`; VPN: `http://10.10.0.2:8123`.

Нажать «Подключить», ввести адрес и долгосрочный токен в локальном интерфейсе. Токен только в памяти страницы: он не сохраняется в файлы, localStorage или репозиторий. Адрес и привязки устройств сохраняются в localStorage этого браузера. После перезагрузки страницы нужно подключиться заново.

Клиент использует официальный WebSocket API: авторизация, получение состояний, подписка state_changed и call_service. Документация: https://developers.home-assistant.io/docs/api/websocket/

Для каждого объекта выбирается основная сущность; можно добавить дополнительные показания. Для light/switch предусмотрено включение/выключение; для light — яркость и цвет, если устройство объявляет поддержку цвета; для media_player — включение/выключение и пауза/пуск. Прочие сущности показывают состояние. Успешная отправка команды не подменяет фактическое состояние: приложение ждёт событие от HA. При отключении соединения телеметрия очищается.

WLED: привязать light-сущность к «Подсветка стола». При активном соединении модель использует реальное состояние, цвет и яркость. Без привязки есть явно обозначенная демонстрация, которая не отправляет команды в дом.

Подключение к реальному серверу требует токена владельца и доступной домашней сети/VPN. В этой версии установка компонентов или изменения конфигурации HA не выполняются.

## Точность

Геометрия пока черновая: в документах есть несогласованные размеры. Контур согласован для прогулки, исходные площади показаны без подмены. Положение и габариты мебели приблизительны. Остальные комнаты без непредоставленной обстановки; интерьеры гаража и бани не выдуманы. Двор схематичен. Эта модель не является строительным чертежом.

Ориентация исправлена по уточнению владельца: при входе в дом кабинет справа; при входе в кабинет котельная слева. Отражены оба этажа, мебель, лестница и участок; координаты перемещения и проёмов согласованы с отражением.

Сборка: `npm run build`. Проверки клиента и геометрии: `npm test`.
