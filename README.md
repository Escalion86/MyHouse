# Мой дом — 3D

Первая интерактивная версия по планам и фотографиям владельца. Два этажа, крыша, открытая мансарда, лестница, кабинет с убранным интерьером, наружные объёмы гаража и примыкающей бани. Расстояние до построек — 4,55 м. Исходные размеры: `HOUSE.md`, `house-data.json`. Допущения доступны кнопкой «Черновая геометрия».

## Запуск и развёртывание

Требуется Node.js 22.12+. Полная инструкция для VPS без Docker, шаблон `.env`, systemd и Nginx находятся в [DEPLOY.md](DEPLOY.md). Пример переменных — [.env.example](.env.example).

```bash
npm ci
# Создать .env по .env.example и заполнить MongoDB, хеш пароля и ключ шифрования.
npm run build
npm start
```

Node-сервер обслуживает API и собранный интерфейс из `dist`. Для production нужен HTTPS-прокси на `127.0.0.1:3001`. Для разработки используйте параметры окружения из DEPLOY.md и запустите `npm run server:dev` и `npm run dev` в отдельных терминалах.

Репозиторий: https://github.com/Escalion86/MyHouse. GitHub Pages не запускает сервер Node.js и MongoDB: для текущей версии с авторизацией и общими настройками разворачивайте проект на VPS.

## Управление

- Обзор: перетаскивание мышью, колесо, масштаб и сброс справа снизу.
- Прогулка: WASD или стрелки, перетаскивание мышью для поворота. На телефоне — экранные стрелки и перетаскивание сцены.
- Комната в списке переносит туда в режиме прогулки. По лестнице можно подниматься и спускаться обычными стрелками: камера плавно меняет высоту, этаж переключается автоматически.
- В коридоре кнопки «Подняться на 2 этаж» / «Спуститься на 1 этаж» ведут по ступеням с поворотом. «Остановиться», Escape, клавиши движения или перетаскивание сцены прерывают проход; затем можно продолжить вручную или кнопкой. Препятствия и пустая часть лестничного проёма блокируют движение.
- Устройства доступны в списке и по нажатию на 3D-объект. В режиме обзора выбор устройства плавно приближает к нему камеру.
- «Экспорт модели GLB» готовит все этажи, крышу и постройки, независимо от текущего вида. Затем нажать «Сохранить GLB». Готовый файл также находится в `exports/my-home-draft.glb`.

## Home Assistant

Адрес сервера задаётся через `HA_URL` в `.env`: `https://home.escalion.ru`. После входа в приложение нажмите «Подключить» и введите долгосрочный токен Home Assistant. Токен хранится в MongoDB в зашифрованном виде; ключ `DATA_ENCRYPTION_KEY` остаётся на сервере. Не добавляйте токен в исходники или переменные `VITE_*`.

Привязки объектов к сущностям сохраняются в MongoDB и доступны после входа с другого устройства. После перезапуска сервер восстанавливает подключение к HA. Старые привязки из localStorage автоматически не переносятся. Выход завершает текущую сессию, а отключение HA удаляет сохранённый токен, сохраняя привязки.

Сервер использует WebSocket API Home Assistant для получения состояний и отправки команд. Интерфейс получает данные через защищённый API приложения. Поддерживаются команды light, switch, media_player и vacuum; остальные сущности используются для показаний.

WLED: привяжите light-сущность к «Подсветка стола». При активном соединении модель использует реальное состояние, цвет и яркость. Демонстрационный режим не отправляет команды в дом.

## Точность

Геометрия пока черновая: в документах есть несогласованные размеры. Контур согласован для прогулки, исходные площади показаны без подмены. Положение и габариты мебели приблизительны. Остальные комнаты без непредоставленной обстановки; интерьеры гаража и бани не выдуманы. Двор схематичен. Эта модель не является строительным чертежом.

Ориентация исправлена по уточнению владельца: при входе в дом кабинет справа; при входе в кабинет котельная слева. Отражены оба этажа, мебель, лестница и участок; координаты перемещения и проёмов согласованы с отражением.

Сборка: `npm run build`. Проверки клиента и геометрии: `npm test`.
